# 사출 공정 불량 예측 및 검사 기준 분석

KAMP 사출성형기 데이터로 불량을 예측하고, **모델 지표와 정상 제품 추가 검사 부담을 함께 평가**한다. 기준 모델, 시계열 특성 비교, 제한된 RF 튜닝에 이어 데이터 활용·모델링·평가 방식을 재검토했다.

**이전 튜닝 결과:** 같은 평가 기록에서 RF 튜닝 후 AP 0.1039→0.1195, F1 0.0889→0.1000, 정상 추가 검사 35→30건. 불량 탐지는 8건 중 2건으로 같고 ROC-AUC는 낮아졌다. 제한된 오탐 감소이며 운영에 충분한 성능으로 판단하지 않는다. 이미 관측한 평가 기간을 재사용한 후속 탐색 실험이다.

**중간 재검토 결과:** 제품별 RF·준지도 RF는 미래 평가에서 개선되지 않았다. 정상 복원 오토인코더는 재현율이 높았지만 특정 제품군 전체를 이상으로 판정했다. 아래 추가 실험 결과에 실패와 선택 기준을 함께 기록했다.

**마지막 완료 실험:** 동일한 시간순 검증에서 클래스 가중치·오버샘플링을 비교해 가중치 없는 RF를 선택했다. 같은 보고 1,000건에서 정상 추가 검사 56건을 유지하며 불량 탐지를 2→5건으로 늘렸지만, AP는 0.1559→0.0995로 낮아졌다. 아래 6절에 비교 조건과 결과를 별도로 기록했다. 이 수치는 앞선 튜닝과 학습·검증 조건이 달라 직접 연결해 개선율을 계산하지 않는다.

제공 자료는 1차 가공된 자동차 부품 사출 기록이다. 서로 다른 생산 건의 공정값이 같다는 이유로 제거하지 않았다. `_id` 중복 잔존 여부를 확인했다. Y=양품/N=불량을 0/1로 매핑하고, 검사 후 불량 사유인 `Reason`을 입력에서 제외했다. 시간·ID·생산 지시 코드는 모델 입력에서 제외하고 시간/생산 지시는 분리와 이력 구간 생성에 활용했다. 수치 0은 일괄 결측 처리하지 않았고 상수/전체 결측 열의 제외와 전처리 학습은 학습 구간에만 적용했다.

라벨이 있는 일부 기록을 이용하므로 연속 전체 생산 이력이나 공장 전체 불량률을 의미하지 않는다. 별도 CSV를 합치거나 라벨 없는 기록을 양품으로 간주하지 않았다.

## 1. 기준 모델

학습은 10월 27일 이전(2,393건/불량 42), 검증은 10월 27~31일(1,837건/불량 10), 평가는 11월 1~6일(1,000건/불량 8)이다. 연도는 모두 2020년이다. 날짜 순서와 ID·생산 지시 묶음의 비중복을 확인했다.

로지스틱 회귀와 RF를 비교하고 검증 AP로 RF를 선택했다. 검증에서 검사 10% 이내 TP 최대/FP 최소 기준을 선택했다. 초기 로컬 결과는 AP 0.1039, TP 2/FN 6/FP 35였다. AP는 Average Precision이며 사다리꼴 PR-AUC와 구분한다.

## 2. 시계열 비교

동일 설비·제품의 기록 간격 중앙값은 약 60초이고 30분 초과 공백은 25개다. 날짜·생산 지시 변경 또는 30분 초과 공백에서 이력을 끊어 33개 구간으로 나눴다. 30분은 분석 가정이며 공장 가동 기준이 아니다.

현재-직전 값 차이, 현재 건을 제외한 직전 5·10건 평균/표준편차, 가용 이력 개수를 추가했다. `shift(1)` 후 rolling을 수행한다. 과거가 부족하면 결측을 유지하고 학습에서 맞춘 대체를 적용한다. 5건은 5분이 아니며 전체 생산 기록 누락을 복구하지 않는다. 미래 센서값 변경이 과거 특성에 영향을 주지 않는지 확인했다.

동일 RF로 3개 시간 구간을 비교한 합산 결과는 현재 값 TP 2/FN 26/FP 35, 시계열 추가 TP 6/FN 22/FP 210이었다. 추가 불량 4건 탐지에 정상 검사 175건이 늘었다. 마지막 구간에서는 TP가 같고 FP만 35→58로 늘었고, 첫 구간의 검사 비율은 조정 9.33%에서 평가 30.4%로 증가했다. 일관된 개선으로 채택하지 않았다.

RG3 LH 미탐 불량 5건과 같은 평가 기간 양품 32건의 쿠션 위치·가소화 시간·평균 배압을 비교했다. 불량값의 범위가 모두 양품 범위 안에 있었고 쿠션 위치와 평균 배압 중앙값은 같았다. 과거 정상 수준에서 변화했다는 사실만으로 불량 원인을 단정할 수 없었다.

## 3. 변수 구성·RF 튜닝

설정 비교용 개발 fold는 2개다. D1은 10월 22일 이전 학습/22일 검증, D2는 23일 이전 학습/23일 검증이다. 설정 선택에는 11월 평가 지표를 사용하지 않았다. 개발 fold는 RG3만, 이후 임계값 구간은 CN7만 있어 제품 구성 편향이 남는다.

| 변수 구성 | 개발 평균 AP |
|---|---:|
| 현재 공정값만 | 0.0458 |
| 일부 시계열 추가(3개 공정 변수) | 0.0369 |
| 전체 시계열 추가 | 0.0371 |

현재 값 구성을 선택하고 깊이 3/6/제한 없음, 최소 잎 표본 5/15, 가중치 없음/balanced_subsample의 12개 설정을 같은 fold에서 비교했다. 트리 수 200, seed 42는 고정했다. 평균 AP 최대, 동률이면 최소 fold AP를 비교했다. 선택은 **깊이 제한 없음, 최소 잎 표본 5, balanced_subsample**이며 개발 평균 AP는 0.0771이다. D1은 그대로, D2에서 향상되어 전체 기간의 안정적 개선으로 볼 수 없다.

설정 선택 후 10월 27일 이전 전체로 재학습했다. 별도의 10월 27~31일에서 **검사 비율 10% 이내 F1 최대**, 동률이면 FP 최소/높은 임계값 순으로 선택했다. 기존 모델에도 같은 규칙을 적용해 공정하게 비교했다. F1은 실제 비용 함수가 아니므로 검사량도 함께 확인한다.

## 4. 같은 평가 기록의 지표

아래는 같은 로컬 환경, 같은 1,000건(불량 8건), 같은 F1 임계값 선택 규칙의 비교다.

| 평가 지표 | 기존 RF | 선택 RF |
| --- | --- | --- |
| AP | 0.1039 | 0.1195 |
| ROC-AUC | 0.9142 | 0.8940 |
| Precision | 5.41% | 6.25% |
| Recall | 25.0% | 25.0% |
| F1 | 0.0889 | 0.1000 |
| Accuracy | 95.9% | 96.4% |
| TP / FN | 2 / 6 | 2 / 6 |
| FP / TN | 35 / 957 | 30 / 962 |
| 전체 검사 | 37 | 32 |

기존 임계값은 0.1710317, 선택 RF는 0.1048018이다. 점수 척도가 다르므로 각 모델의 별도 조정 구간에서 선택했다. 초기 TP 최대 임계값과 숫자는 다르지만 기존 RF의 이 평가 구간 판정 결과는 같았다.

**결론:** 같은 재현율 25%에서 오탐 5건(35→30, 약 14.3%)을 줄였다. AP와 F1은 상승했지만 ROC-AUC는 0.9142→0.8940으로 낮아졌다. 불량 6건을 여전히 놓쳐 충분한 성능이라고 판단하지 않는다. 평가 F1이 더 높아 보이는 보조 행을 보고 주 기준을 다시 선택하지 않았다. 기본 0.5, 변수 변경만, 원래 TP 최대 규칙의 결과도 노트북에서 확인할 수 있다.

## 5. 데이터 활용·모델링·평가 방식 재검토

튜닝 후에도 충분한 재현율을 확보하지 못해 제품별 모델링, 라벨 없는 데이터 활용, 정상 패턴 기반 모델을 추가로 비교했다.

### 데이터 검증

- 라벨 없는 전체 기록: 795,315건
- 같은 설비·제품: 71,180건
- 기존 라벨 자료와 생산 시각·설비·제품이 같은 기록: 1,984건 제외
- 라벨 없는 자료 자체의 사건 중복: 84개 키의 168행 모두 제외
- 중복 제외 후 69,028건 중 실제 학습 종료 이전 30일 후보: CN7 18,240건, RG3 7,892건

ID가 다르더라도 같은 생산 사건이 겹칠 수 있음을 확인했다. 실제 학습에 선택된 가상 라벨은 CN7 양품 1,000건, RG3 양품 666건이며 가상 불량은 0건이었다. 전체 후보를 학습했거나 불량 정답을 확보했다고 표현하지 않는다.

### 평가 설계 변경과 통제

CN7은 기존대로 10월 27일 이전 학습/27~31일 조정이다. RG3는 10월 23일 이전 학습/23일 조정으로 바꿔 제품별 기준을 확인할 수 있게 했다. 평가는 동일한 11월 1~6일 1,000건이다. 통합 RF도 같은 재분리에서 다시 학습한다. 이전 튜닝의 결과와 직접 개선율을 계산하지 않는다.

RF는 트리 200, 깊이 제한 없음, 최소 leaf 5로 고정했다. 준지도는 확신도 0.95/0.99, 최대 2회, 실제 클래스별 학습량을 기준으로 회차당 추가량 제한, 가상 라벨 가중치 0.25다. 전처리는 실제 학습 데이터로만 맞춘다. 제품별 조정 AP로 지도/준지도 후보를 고르고, 각 모델의 조정 구간에서 검사 10% 이내 F1 최대 임계값을 선택한다.

오토인코더는 실제 학습 양품만 사용하고 하나의 스케일러를 양품/불량에 동일하게 적용한다. 15→5→15 구조, 잡음 0.03, 최대 300 epoch의 소형 CPU 신경망으로 복원 MSE를 이상 점수로 사용했다. 두 모델 모두 최대 epoch에 도달하여 최적 수렴을 주장하지 않는다.

### 같은 평가 기록의 결과

| 방법 | TP | FN | FP | 재현율 | F1 |
|---|---:|---:|---:|---:|---:|
| 재분리 통합 RF | 1 | 7 | 19 | 12.5% | 0.0714 |
| 제품별 지도 RF | 0 | 8 | 0 | 0% | 0 |
| 제품별 준지도 RF(0.95/0.99) | 0 | 8 | 0 | 0% | 0 |
| 조정 AP로 선택한 RF 조합 | 0 | 8 | 0 | 0% | 0 |
| 제품별 오토인코더 | 7 | 1 | 67 | 87.5% | 0.1707 |
| 조정 AP로 RF/AE 중 선택 | 0 | 8 | 0 | 0% | 0 |

제품별 모델은 점수 척도가 달라 AP/ROC-AUC를 제품별로 보고한다. 단순 연결한 전체 AP 대신 제품군 평균 AP를 별도 표기한다. 검사 대상이 0인 행의 정밀도는 정의되지 않으며 노트북 합산 표에서 NaN으로 표시한다.

**채택 판단:** 준지도는 가상 양품만 추가되어 불량 패턴 부족을 보완하지 못했고, 조정에서 선택한 모델은 평가 불량을 모두 놓쳤다. 오토인코더의 재현율 87.5%는 RG3 74건 전체를 이상으로 분류한 결과라 실용적인 선별 개선으로 보지 않는다. 제품별 조정 AP에서도 AE가 RF보다 낮아 최종 선택되지 않았다. 높은 평가 재현율만 보고 사후에 AE로 선택을 바꾸지 않았다.

### 개선 이력

데이터 정제·기준 모델 → 시계열 특성 비교 → 변수 구성·RF 튜닝으로 일부 지표 개선 → 낮은 재현율 확인 → **데이터 활용·모델링·평가 방식 재검토** → 사건 중복 제거·제품별 지도/준지도·정상 복원 비교 → 추가 방식의 성능 한계 확인.

## 6. 데이터 관계 점검과 불균형 처리 비교

원본과 가공 파일을 다시 점검한 결과 `moldset_labeled.csv`의 ID는 원본에 모두 있었고 동일 ID의 라벨도 일치했다. 이를 새 데이터처럼 추가하지 않았다. 가공 CN7 불량 17건 중 11건, RG3 불량 25건 중 25건에 동일한 공정값의 정상 기록이 존재했다. 이는 서로 다른 사건일 수 있어 라벨 오류로 단정하지 않았다. 원본의 제품 LH/RH 구분을 유지했다.

### 비교 조건

- RF 200개 트리, 깊이 제한 없음, 최소 잎 표본 5, seed 42 고정.
- 가중치 RF(`balanced_subsample`), 가중치 없는 RF, 불량/정상 학습 비율 0.25 및 1.0 오버샘플링을 비교.
- D1: 10/22 이전 학습→10/22 검증, D2: 10/23 이전 학습→10/23 검증, D3: 10/27 이전 학습→10/27~31 검증.
- 검증 평균 AP가 기준보다 높고 3구간 중 2구간 이상 개선될 때만 후보를 채택.
- 검증 OOF 예측에서 검사량 10% 이내 F1 최대 임계값을 고정. 이 제한이 이후 기간에서도 유지된다는 보장은 없음.
- 최종 학습: 11월 이전 4,230건/불량 52건. 보고: 11월 1~6일 1,000건/불량 8건.
- 전처리와 오버샘플링은 학습 구간만 사용. 보고 결과로 모델·임계값을 재선택하지 않음.

### 검증 결과

| 설정 | 3구간 평균 AP |
|---|---:|
| 가중치 RF | 0.0867 |
| 가중치 없는 RF | **0.1251** |
| 오버샘플링 비율 0.25 | 0.1168 |
| 오버샘플링 비율 1.0 | 0.0816 |

가중치 없는 RF가 3개 구간 중 2개에서 기준보다 높은 AP를 보여 선택되었다. 모든 구간의 개선이나 통계적 유의성을 뜻하지 않는다.

### 동일 보고 기록의 결과

| 지표 | 가중치 RF | 선택된 가중치 없는 RF |
|---|---:|---:|
| AP | 0.1559 | 0.0995 |
| ROC-AUC | 0.7507 | 0.8946 |
| Precision | 3.45% | 8.20% |
| Recall | 25.0% | 62.5% |
| F1 | 0.0606 | 0.1449 |
| TP / FN | 2 / 6 | 5 / 3 |
| FP / TN | 56 / 936 | 56 / 936 |
| 전체 검사 | 58 | 61 |

**판단:** 정상 추가 검사 56건을 유지하며 탐지 2→5건, 미탐 6→3건으로 바뀌었다. 하지만 AP는 하락해 전반적인 순위 예측 개선으로 해석하지 않았다. 평가 불량이 8건뿐이며 이미 관측한 기간의 후속 탐색 결과다.

이 비교는 3절의 튜닝과 최종 학습 범위·검증 임계값 선정 구간이 다르다. AP 0.1195와 직접 개선율을 계산하지 않는다. 마지막 결과만 남기지 않고 효과가 제한적이었던 시계열·준지도 실험과 판단도 함께 보존했다.

## 한계와 다음 검증

- 기존 평가 결과를 알고 시작한 후속 탐색이다. 시간순 분리를 해도 선택 편향이 사라지지 않는다. 새로운 기간으로 검증해야 한다.
- 평가 불량 8건이므로 한 건이 재현율 12.5%p를 바꾼다. 통계적 유의성이나 현장 성능 향상을 주장하지 않는다.
- RG3 LH 학습 불량이 없으며 각 구간의 제품 구성이 다르다. 추가 라벨 확보와 제품별 검증이 필요하다.
- 변수 구성을 먼저 고른 뒤 해당 구성만 튜닝하는 제한된 단계적 탐색이다. 모든 조합의 최적값을 찾은 것은 아니다.
- 사이클 종료 후 공정 요약값을 이용하는 검사 우선순위 시나리오다. 사출 전 예측·실시간 제어·조건 추천·불량 원인 입증은 범위 밖이다.
- 검사 시간과 불량 유출 비용이 없어 비용 절감액은 계산하지 않는다.
